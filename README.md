***DESCRIPTION****
The Mathrix, is a intermediate level maths quiz game till for year 9 students. Having 3 levels(Easy/Medium/Hard) and save their score just with entering username. New players can register and existing players can continue. Its an user interactive game , which directs and show messages to direct users.

***HOW TO USE***
*Open the game window
*New players use start button/ registered players have to continue, for this you have to *know you registered username.

*Then click on specified level you want(easy/medium/hard)
*Then its all done for the player

***Game Feature***

*3 options of level selection 
*instant answer, feedback
*Minimum points for winning
*easy=50
*medium=70
*hard=80, but have time for each question of 80 seconds


***REQUIREMENTS***
